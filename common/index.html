    공통 안전 수칙

    • 위험하다고 판단되면 누구든 “STOP”을 외치고 안전요원에게 알립니다.
    • STOP 선언 시 음악 정지 → 조명 전환 → 안내방송, 재개는 안전책임자 승인 후입니다.
    • 무대 앞 2m 완충 펜스 안은 출입 통제 구간입니다.
    • LPG 반입 금지, 비상통로(소방차 통로 3.5m 이상) 상시 확보.
    • 레이저는 관람객 직접 조사 금지(상향 15도), 20:00 이후 소음 65dB 이하.
    • 모든 문의·변경은 종합상황실로 보고합니다.
