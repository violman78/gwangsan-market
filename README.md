# 제3회 광산세계야시장 — 공유 사이트 (GitHub Pages)

휴대폰에 최적화된 운영 안내 사이트입니다. 서버·빌드 도구 없이 **폴더 그대로 올리면 동작하는 정적 사이트**입니다.

## 구성
| 폴더 | 내용 |
|---|---|
| `index.html` | 홈 — 오늘의 진행(행사 당일 휴대폰 시계 기준 자동 표시), 역할 선택 |
| `performers/` | 출연팀 8팀 안내(이미지 + 안내문) |
| `parade/` | 퍼레이드 종합안내, 출발지점 A/B, 다국어 초대장, 퍼니밴드·아냐포·의선전통공연단 |
| `staff/` | 안전·경호·진행 인력 파트별 배치도와 위치, 임시주차장, 행사차량 안내표지 |
| `booth/` | 먹거리 차량 진입, 현장 담당자, 부스 배치도 |
| `crew/` | 제작 파트 시나리오 8종(총괄·무대·조명·음향·촬영·사회자 공통·손주은·장하라) — 순서별 접기/펼치기 |
| `me/` | **내 역할 찾기** — 성명 또는 휴대폰 번호 입력 → 본인 배치 + 본인이 받을 안전교육만 표시 (홈 화면에도 같은 입력창) |
| `edu/` | 안전교육 7과정, 퀴즈, 이수 확인서, 이 기기의 이수 기록 |

| `assets/`, `img/` | 스타일, 스크립트, 최적화된 이미지 |
| `admin/` | 총괄 전용(일정 수정 · 긴급공지) — 메뉴에 없음, 주소를 총괄만 보관 |

| `FIREBASE_SETUP.md` | 서버 연결 안내 |
| `_build/` | 사이트 생성 스크립트 (업로드 제외 — `.gitignore` 처리됨) |

## 새 기능 요약
- **내 역할 찾기**: 성명·휴대폰 번호(인력) / **팀명(출연팀)** / **나라명(퍼레이드)** / **파트명(제작)** 입력 → 내 위치(지도 줌인)·내 교육만 표시. 한 번 확인하면 다음부터 처음 화면에 바로 표시됩니다.
- **안전교육은 퀴즈 없이** 읽고 “교육 이수 확인” → 이수 확인서. 하단 **캡처하기** 버튼으로 이미지 저장.
- **총괄 수정 · 긴급공지(진동) · 공유 채팅(사진 전송)**: `FIREBASE_SETUP.md` 안내대로 서버를 연결하면 동작합니다. (연결 전에는 “서버 연결 전”으로 표시)

## GitHub Pages 올리는 순서 (처음 1회, 약 5분)
1. GitHub에 로그인 → 우측 상단 **+ → New repository**. 이름은 영문(예: `gwangsan-market`), 공개 범위 **Public**으로 생성.
2. 저장소 화면에서 **uploading an existing file** 클릭 → 이 폴더 **안의 내용 전체**(index.html, assets, img 등. `_build` 제외)를 끌어다 놓고 **Commit changes**.
   - 파일 수가 많아 한 번에 안 올라가면 폴더를 나눠 여러 번 올려도 됩니다.
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch **main / (root)** → Save.
4. 1~2분 뒤 `https://사용자명.github.io/저장소명/` 주소가 생성됩니다. 휴대폰(LTE)으로 접속해 확인하세요.
5. `…/qr/` 에서 QR을 만들어 단체 톡방·현장에 부착합니다.
6. 홈 화면에 추가: 사파리 공유 → “홈 화면에 추가” / 크롬 메뉴 → “홈 화면에 추가”.

## 수정 방법
- 내용이 바뀌면 원본(상위 폴더)을 고친 뒤 `python3 _build/build_site.py` 실행 → 바뀐 파일만 다시 업로드(같은 방식으로 Commit) → 단체 톡방에 “○○ 변경” 한 줄 공지.
- 인력배치 **성명 표시**가 필요하면 `_build/build_site.py` 맨 위 `INCLUDE_ROSTER = True` 로 바꿔 다시 생성하세요(연락처는 어떤 경우에도 사이트에 넣지 않습니다).

## 공개 범위 안내 (중요)
- GitHub Pages(무료)는 **주소를 아는 누구나 열람**할 수 있습니다. 검색 노출은 막아 두었지만(noindex/robots) 비밀번호 보호는 없습니다.
- 그래서 이 사이트에는 **개인 연락처(스태프·학교 담당자), 개인별 배정 명단, 계약·예산·산출 자료를 넣지 않았습니다.** 연락처는 종합상황실 대표번호(010-6693-5720)만 표시합니다.
- 시나리오 파일의 팀 대표자 이름은 공개용에서 제외했습니다. 개인별 배치는 단체 톡방/총괄이 개별 안내하세요.
- 안전교육 이수 기록은 각자 휴대폰에만 저장됩니다(서버 집계 없음).
- 행사 종료 후에는 저장소를 **Private으로 전환하거나 삭제**하세요.

## 내 역할 찾기 (me/) 동작 방식
- 입력한 이름/번호(뒤 8자리)로 **이 기기 안에서** 암호 해제(AES-GCM) → 해당 사람의 배치·교육만 표시합니다. 서버로 전송되지 않습니다.
- 사이트 파일(`assets/lookup-data.js`)에는 이름·번호가 **그대로 들어 있지 않고** 암호화된 값만 있습니다.
- 명단을 바꿨을 때: `python3 _build/make_lookup.py && node _build/encrypt.js` → `python3 _build/build_site.py` → 파일 다시 업로드.
- 같은 이름이 둘 이상이면 모두 표시되고, 휴대폰 번호로 입력하면 한 명만 표시됩니다.
- 명단에 없는 출연팀·부스 운영자·사회자 외 인원은 홈의 “목록에서 직접 선택”을 쓰세요.
- 참고: 이름은 추측이 쉬워 보안 장치가 아니라 **편의 기능**입니다. 확인되는 정보는 배치 위치·교육뿐이며 연락처는 표시하지 않습니다.
